#### ¿Qué es [GitHub](https://github.com/)?

GitHub es una **plataforma en la nube que permite a los desarrolladores almacenar, compartir y gestionar
sus proyectos de código fuente utilizando el sistema de control de versiones Git**

Se puede ver como _una gran biblioteca digital o red social_, donde se guardan los archivos de un programa junto
con el historial de todos los cambios realizados.

Sirve para:
- _**Control de versiones**_
- _**Trabajo en equipo**_
- _**Colaboración abierta**_
- _**Portafolio profesional**_

> Diferencia clave entre Git y GitHub:
> - Git: Es el software libre instalado en tu ordenador que gestiona y registra los cambios en los archivos de manera local.
> - GitHub: Es el servicio web en la nube (propiedad de [Microsoft](https://es.wikipedia.org/wiki/Microsoft)) que sirve para almacenar y sincronizar esos proyectos de Git en internet para que otros puedan verlos y colaborar.

Además, GitHub es el gran almacén global de código, donde los desarrolladores no solo guardan sus proyectos, sino que comparten, reutilizan y mejoran bloques de código creados por personas de todo el mundo. Un ejemplo de bloque puede ser:

``` #Este programa saluda y suma dos números
nombre = "Desarrollador"
print(f"¡Hola, {nombre}!")

# Operación matemática simple
numero_1 = 5
numero_2 = 10
resultado = numero_1 + numero_2

print(f"La suma de {numero_1} y {numero_2} es: {resultado}")
```
